# 🔐 Personal Manager v2.0

Современное кроссплатформенное десктопное приложение для криптографической защиты личных данных, паролей и ведения зашифрованного дневника. 

---

## 🛠 Архитектурные обновления в Версии 2.0

Система прошла полный рефакторинг и переведена на гибридную архитектуру **«Лаунчер + Локальный веб-сервис»**:

### 1. Десктопный Лаунчер (`launcher.py`)
* **Технологии**: Написан на чистом **Tkinter**.
* **Дизайн**: Кастомный оранжево-серый GUI-интерфейс в стиле хакерского сейфа.
* **Автономия**: Сам находит изолированное виртуальное окружение `.venv` и поднимает бэкенд в один клик без использования терминала.

### 2. Ядро и Интерфейс (`main_operation.py`)
* **Технологии**: Нативно работает на движке **Streamlit**.
* **Стилизация**: Интегрирован кастомный системный файл настроек темы `config.toml`.

---

## 🛡️ Броня Бэкенда: Трёхслойные Декораторы

Все CRUD-операции СУБД SQLite и модули авторизации защищены многоуровневыми «матрёшками» из кастомных декораторов:

* **`@db_logger` + `@time_tracker`** 
  * Переводит СУБД в стелс-режим (в консоли больше нет лишних принтов).
  * Автоматически замеряет скорость работы процессора и криптографии с точностью до микросекунд.
  * Ведёт структурированный файл отчётов `utils/system_logs.log`.
* **`@retry_on_lock`** 
  * Защищает SQLite от блокировок транзакций (`database is locked`).
  * При сбое молча делает паузу и производит до 3 повторных попыток выполнения.
* **`@clean_inputs`** 
  * Автоматический «дворник» для входящих данных.
  * Перехватывает аргументы и словари фронтенда, очищая текстовые поля от случайных невидимых пробелов через `.strip()`.

## 🚀 Требования и Запуск

Приложение полностью кроссплатформенно и оптимизировано для **macOS** и **Linux Mint**.

### Быстрый старт:
Просто запустите главный файл лаунчера из корня проекта:
```bash
python launcher.py
```
*Лаунчер сам активирует окружение, запустит сервер защищённой СУБД и откроет Личный Сейф в вашем браузере.*
