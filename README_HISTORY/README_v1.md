# ___Персональный менеджер___
---
> Команда для запуска через терминал `./run_desktop.sh`. Скрипт автоматически сам установить виртуальное окружение и все зависимости  
> В программе может быть зарегестрирован только один пользователь
### ___Пакет .streamlit___
---
> Настройка темы 
### ___Пакет db_manager___
---
> Содержит логику работу с базой данных 
> База данных создается в корень папки
### ___Пакет utils___
---
> Содержит логику работы с хэшированием паролей
### ___Пакет view___
---
> Содержит логику работы с интерфейсом и отображением его на экране
### ___Модуль main_operation___
---
> Содержит логику работы первичного окна приветсвия. В зависимости от условия переключает окна
### ___Файл requirements.txt___
---
> Содержит файл зависимостей
### ___Файл run_desktop.sh___
---
> Исполняемый скрипт
